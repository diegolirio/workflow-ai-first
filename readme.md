# Agentes de IA na Prática
### Ciclo de Vida do Desenvolvimento de Software

Modelo de trabalho para times mistos de PO, Dev e QA — do refinamento de negócio até testes em produção, conduzido por agentes de IA com decisão humana em cada gate.

> **A IA executa. O humano decide.**  
> Nunca terceirize suas decisões. Deu certo foi você. Deu errado também foi você.

---

## O modelo em 3 fases

**Fase 1 — Upstream (cadência de produto)**  
Exploratório → Refinamento de Negócio → Design de Telas → Quebra em Estórias

**Fase 2 — Downstream: Engenharia (cadência de dias)**  
Refinamento Técnico com `design.md` → Implementação paralela por stack

**Fase 3 — Downstream: Qualidade**  
Spec-Driven Testing com agentes de QA autônomos — sem reescrita de critérios

A fila de Estórias prontas é o único ponto de contato entre as fases. Nenhum lado espera o outro.
